# BL-012: Support NVIDIA Nemotron Ultra AI provider

Status: implemented
Run: autonomous
Value: High
Effort: Small
Blocked by: -
Question rounds: 1 round: 10 findings (6 critical, 4 minor) - all resolved in sections 4, 5, 7, 8, and 9

## 1. What and why
Allow Kidly Storiez to generate story plans and stream interactive bedtime stories using NVIDIA NIM's `nvidia/nemotron-3-ultra-550b-a55b` model in addition to Anthropic Claude. This lets the team run and verify the live demo with an NVIDIA `nvapi-...` key without changing any frontend code or client-side privacy rules.

## 2. Prerequisites
- `BL-001` code merged on `main` (completed in PR #1).
- An NVIDIA API key (`NVIDIA_API_KEY`, format `nvapi-...`) from `build.nvidia.com`, stored only in local `.env` or host environment variables (never committed).

## 3. Scope
In:
- Server-side NVIDIA NIM Chat Completions adapter (`src/nvidia.js`) using Node 20+ built-in `fetch` (`https://integrate.api.nvidia.com/v1/chat/completions`), default model `nvidia/nemotron-3-ultra-550b-a55b`.
- Shared provider interface and precedence in `src/app.js` and `src/server.js` via `AI_PROVIDER` (`auto`, `nvidia`, `anthropic`), `NVIDIA_API_KEY`, `NVIDIA_MODEL`, and `NVIDIA_BASE_URL`, preserving existing `createApp({ client })` behaviour for Claude tests.
- Streaming SSE parsing that forwards non-empty string `delta.content` chunks only (filtering out `null`/`undefined` and `reasoning_content`), strips `@@@` via `MarkerSplitter`, and parses endings via `parsePartTail` / `parsePlan`.
- Documentation updates in `.env.example`, `docs/SETUP.md`, and `architecture.md` (ADR-006).
- Automated integration tests (`BL-012-T01` through `BL-012-T05`) using an injected mock `fetchImpl`.

Out:
- Client-side AI calls or UI changes (`public/` remains unchanged).
- Multi-provider fallback chains or prompt tuning per model (`BL-009` covers safety and quality evaluations).
- Hosting/deployment setup (`BL-002`).

## 5. Data, interfaces and architecture impact
- New file `src/nvidia.js`: exports `createNvidiaProvider({ apiKey, model = "nvidia/nemotron-3-ultra-550b-a55b", baseUrl = "https://integrate.api.nvidia.com/v1", fetchImpl = globalThis.fetch, timeoutMs = 30000 })`:
  - Validates non-empty `apiKey`, trims and strips trailing `/` from `baseUrl`, posts to `${baseUrl}/chat/completions` with `Authorization: Bearer ${apiKey}`.
  - `label`: `"live (NVIDIA Nemotron)"`.
  - `async plan({ system, user, signal })`: sends `messages: [{ role: "system", content: system }, { role: "user", content: user }]`, `stream: false`, `temperature: 0.4`, `max_tokens: 8192`. Returns `{ refused: true, text: "" }` when `finish_reason` is `"content_filter"` or `"refusal"`, or `message.refusal` is truthy; throws `Error` with `.status` if `finish_reason === "length"` or non-2xx HTTP; otherwise returns `{ refused: false, text: message.content || "" }`.
  - `async *streamStory({ system, user, signal })`: sends `stream: true`, `temperature: 0.8`, `max_tokens: 8192`. Yields `{ type: "text", text }` for each non-empty string `choices[0].delta.content`, yields `{ type: "refused" }` on `finish_reason` `"content_filter"`/`"refusal"` or `delta.refusal`, throws `.status` Error on non-2xx HTTP, upstream SSE `{ error }`, malformed SSE JSON, or `finish_reason === "length"`. Never includes `apiKey` in error messages.
- Modified `src/app.js`:
  - Exports `resolveProvider(env = process.env)` (used by both `createApp` and `src/server.js`) returning `{ provider, label }`.
  - `createApp({ client, provider, env = process.env, limit } = {})`: if `provider !== undefined` uses `provider`; else if `client !== undefined` wraps `client` with `createAnthropicProvider(client)` (or `null` when `client === null`); else calls `resolveProvider(env)`.
  - Anthropic adapter exposes `{ label: "live (Claude)", plan, streamStory }` (yielding `{ type: "reset" }` on `fallback` blocks).
- Modified `src/server.js`: uses `resolveProvider(process.env).label` (`"live (NVIDIA Nemotron)"`, `"live (Claude)"`, or `"offline demo story only"`).
- Modified `.env.example`, `docs/SETUP.md`, `architecture.md` (adds ADR-006).
- Architecture impact: ADR-006 adds an OpenAI-compatible NVIDIA NIM backend adapter alongside `@anthropic-ai/sdk` while keeping all AI keys and prompts server-side (ADR-004, NFR-06).
- External service stand-in in tests: injected mock `fetchImpl` returning synthetic JSON and `ReadableStream` SSE chunks.

## 7. Behaviour and rules
1. Environment variable parsing in `resolveProvider(env)`:
   - Trim strings; blank/whitespace-only values count as unset (`""`).
   - `AI_PROVIDER`: trimmed and lowercased; unset/blank defaults to `"auto"`. `"nvidia"` requires non-empty `NVIDIA_API_KEY`; `"anthropic"` requires non-empty `ANTHROPIC_API_KEY`; `"auto"` picks `NVIDIA_API_KEY` if set, else `ANTHROPIC_API_KEY` if set, else `null`. Unrecognized values log a warning and return `null`.
   - `NVIDIA_MODEL` and `NVIDIA_BASE_URL` fall back to defaults when unset/blank.
2. `/api/plan`: creates a request-scoped `AbortController` aborted on `res.on("close")` when `!res.writableEnded`. Calls `provider.plan({ system: SYSTEM_PROMPT, user: ..., signal })`. If `refused` is true, returns `{ safe: false, message: "We could not make a story from these notes. Try describing the day a little differently." }`. Child's real name is never sent (SR-01, ADR-003).
3. `/api/story`: creates a request-scoped `AbortController` aborted on `res.on("close")` when `!res.writableEnded`. Iterates `provider.streamStory(...)`:
   - `"reset"` resets `MarkerSplitter` and sends `{ type: "reset" }`.
   - `"text"` feeds `splitter.push(ev.text)` and sends `{ type: "text", text }` when non-empty.
   - `"refused"` sends `{ type: "error", error: "refused" }` and ends immediately **without** calling `splitter.flush()` or emitting `options`/`end`.
   - On clean end without refusal, flushes `splitter.flush()` and emits `end` (`partIndex === 2`) or `options` (`partIndex < 2`).
4. Listener cleanup: remove `close` listener and clear timers in `finally` on both endpoints.

## 8. Edge cases and failure cases
- Missing `NVIDIA_API_KEY` and `ANTHROPIC_API_KEY`: `GET /api/config` returns `{ live: false }`, `/api/plan` and `/api/story` return HTTP `503` `{ error: "offline" }` so the client uses `public/fallback.js`.
- `createApp({ client: null })` called in tests while `.env` has `NVIDIA_API_KEY`: explicit `client: null` still forces offline mode (`live: false`).
- Upstream HTTP non-2xx, network error, `finish_reason: "length"`, or 30,000 ms idle timeout: `/api/plan` logs `err?.status ?? "", err?.message` without secrets and returns HTTP `502`; `/api/story` emits NDJSON `{ type: "error", error: "unavailable" }`.
- SSE framing edge cases: uses `TextDecoder("utf-8", { stream: true })`, splits on `\r?\n`, trims lines, ignores blank lines, `: ...` comments, and `event:`/`id:`/`retry:` lines, parses `line.slice(5).trim()` for `data:`, stops at `[DONE]`, flushes remaining buffered line on EOF, and throws if a `data:` line has invalid JSON or an `{ error }` payload.
- `delta.content` is `null` or `undefined`, or `delta.reasoning_content` is present: ignored; never passed to `MarkerSplitter.push()`.

## 9. Acceptance criteria (named tests)
- `BL-012-T01` (integration) `/api/plan` uses the NVIDIA provider with `Bearer` auth and `nvidia/nemotron-3-ultra-550b-a55b`, omits the child's name, and returns a signed plan.
- `BL-012-T02` (integration) `/api/story` streams NVIDIA SSE `delta.content` chunks (CRLF, split lines, `null` content and `reasoning_content` ignored, `@@@` stripped) as NDJSON `text` and `options`.
- `BL-012-T03` (integration) NVIDIA provider maps upstream HTTP errors and `finish_reason: "length"` to `502` / `{ type: "error", error: "unavailable" }`, and maps `content_filter` / `refusal` on both `/api/plan` and `/api/story` to refusal without emitting `options` or `end`.
- `BL-012-T04` (unit) `resolveProvider` and `createApp` respect `AI_PROVIDER` (`auto`, `nvidia`, `anthropic`, invalid, blank strings), trailing `/` normalization on `NVIDIA_BASE_URL`, and `client: null` overriding env vars.
- `BL-012-T05` (integration) Client disconnect aborts the upstream `fetch` `AbortSignal`, and exceeding `timeoutMs` aborts a stalled upstream call.

## 10. Human acceptance test
1. Copy `.env.example` to `.env`, set `NVIDIA_API_KEY` to a valid NVIDIA key, and run `npm start`.
2. Verify the terminal prints `live (NVIDIA Nemotron)`.
3. Open `http://localhost:3000` on your browser or phone, enter a child's first name, age, hero, and what happened today, and tap `Make a story plan`.
4. Verify a live plan appears (without real names) and you can approve it and play through both choices to a calm ending.
5. Clear `NVIDIA_API_KEY` and `ANTHROPIC_API_KEY` in `.env`, restart, and verify `Offline story` still works.
