# BL-018: The safety eval runs on whichever AI provider the app uses

Status: implementation
Run: small fix
Value: High
Effort: Low
Blocked by: BL-017 (built on its branch; both change `eval/run.js`)

## What and why
The safety eval (BL-009) could only call Claude, but the team has no Anthropic key and
the app now runs on NVIDIA Nemotron (BL-012). The eval must test the model the app
actually uses.

## Where
`eval/run.js` (`main`, the judge, call recording), `test/eval.test.js`.

## Change
- The eval picks its AI exactly like the app: `resolveProvider` from `src/app.js`
  (`AI_PROVIDER`, `NVIDIA_API_KEY`, `ANTHROPIC_API_KEY`), and drives the real routes
  through that provider.
- On NVIDIA: the same model grades the stories (the summary warns that this can be
  lenient). Each call is recorded with its model; NVIDIA does not report tokens to the
  app and has no published price, so the summary shows "Calls made: N (provider
  credits; no published price, cost not computed)" and `--max-usd` does not apply. The
  run still needs `--yes`, and `--reps` is still capped at 10.
- On Claude: unchanged (own judge model `EVAL_GRADER_MODEL`, cost from tokens, budget).
- No key at all: "No AI key is set. Put NVIDIA_API_KEY (or ANTHROPIC_API_KEY) in .env.
  Nothing was sent." and exit 1.

## Acceptance criteria
- `BL-018-T01` With an NVIDIA key, the eval calls NVIDIA's chat endpoint with the key and the Nemotron model for plans, story parts and grades, and the summary names NVIDIA, shows the call count and the same-model note.
- `BL-018-T02` On NVIDIA, a run without `--yes` shows the case and call count and sends nothing.
- `BL-018-T03` Refused, failed or stopped calls are still counted (and shown as such), and a provider chosen without its key names the missing key.

## Human acceptance test
1. Put your NVIDIA key in `.env` as `NVIDIA_API_KEY=...`.
2. Run `npm run eval`. You should see "21 cases x 1 rep(s) on NVIDIA Nemotron ..." and "About 85 calls ...", and nothing is sent.
3. Run `npm run eval -- --yes`. After a few minutes you get the pass-rate table, with "model: NVIDIA Nemotron ..." at the top.

## Out of scope
- A separate, stronger judge model on NVIDIA (possible later via a judge provider setting).
- Prompt changes for Nemotron (after the first run).
