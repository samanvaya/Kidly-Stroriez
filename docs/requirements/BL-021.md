# BL-021: NVIDIA provider: set reasoning per call and stream plans

Status: implementation
Run: small fix
Value: High
Effort: Low
Blocked by: -

## What and why
Two issues in the NVIDIA provider from BL-012, found while building BL-020:
1. It never sends `reasoning_effort`, so Nemotron Ultra reasons at its default
   ("high"). Story parts then start slowly (NFR-01) and calls risk the 30-second timeout.
2. Plans use a non-streamed call. NVIDIA's API reference says a non-streamed call can
   be answered with HTTP 202 "pending" (to poll later), which the provider treats as
   an error, so the parent would see "not available".

## Where
`src/nvidia.js` (`createNvidiaProvider`), `src/app.js` (`resolveProvider` passes the
new settings), `.env.example`, `docs/SETUP.md`.

## Change
- Every call sends `reasoning_effort`: plans `medium` (they decide whether a note is
  safe for a story), story parts `none` (fast first words). Settings
  `NVIDIA_PLAN_REASONING` and `NVIDIA_STORY_REASONING` (`none`, `medium`, `high`)
  override; any other value stops the server with a clear error.
- Plans are streamed too (`stream: true`, `Accept: text/event-stream`) and put back
  together; a reply that is plain JSON (a server that ignores `stream`) still works.
- A leading `<think>…</think>` block in the reply text is removed, in case the API
  returns reasoning there instead of in `reasoning_content` (never shown to the child).

## Acceptance criteria
- `BL-021-T01` Plans and story parts are both streamed, with reasoning `medium` and `none`.
- `BL-021-T02` A streamed plan is put back together; a streamed refusal is a refusal.
- `BL-021-T03` A `<think>…</think>` block (also split across chunks, and in a JSON reply) is removed; a reply that only starts like a tag is kept.
- `BL-021-T04` `NVIDIA_PLAN_REASONING` / `NVIDIA_STORY_REASONING` are used; a wrong value is rejected with a clear message.

## Human acceptance test
1. With your NVIDIA key in `.env`, run `npm start` and open the app.
2. Make a plan, approve it, and watch the story: the first words appear within a few seconds.
3. Finish a story: no stray reasoning text ("<think>", "the child is five, so...") appears anywhere.

## Out of scope
- BL-019 (parallel pre-generation, Max).
- Prompt changes for Nemotron (after the first live eval).
